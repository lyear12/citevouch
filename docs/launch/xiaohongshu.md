# 小红书

*小红书不是发链接的地方，是发「一条能截图的东西」的地方。所以这里的正文不含链接，含的是两张可以直接截图发出去的画面：一张是工具说「不」，一张是那句话在第 6 页被划出来。链接放评论区。*

---

## 笔记一（工具说「不」）

**标题**

```
论文里那句"语料有154391句"，我让程序去PDF里找了一遍
```

**正文**

写论文最虚的一刻，是把一个数字写进正文、却说不清它到底是哪一页来的。

我给自己写了个东西：在论文里那句话旁边，写清楚「这份 PDF、第 6 页、逐字原文是这句」。然后程序每次改稿都会重新打开 PDF，告诉你还在不在。

截图这张是它对着我自己的草稿说的：4 条对得上，1 条找不到。因为那条我引的句子根本在另一篇论文里。

最有用的不是它对的时候，是它说「找不到」的时候。

## 笔记二（那不勒斯式的那一页）

**标题**

```
"这句话在第6页"——终于是我敢写进方法论的一句话
```

**正文**

以前写「该语料包含 154,391 句」这种句子，靠的是记忆和运气。

现在的流程是三步：

1. 复制 PDF 里的原句，粘到稿子旁边
2. 标上页码
3. 提交前跑一次检查

它只做一件事：确认那句话，在你说的那一页，逐字都在。

不联网、不读你的账号、不看任何云端数据，只读你电脑上的文件。

（工具是开源的，评论区说）

#论文写作 #科研工具 #博士日常 #写论文

## 发帖备注

- **不要发链接进正文。** 小红书对正文里的外链基本是限流处理，放评论区且只放一次。
- **第一张图就是全部。** 封面用 `docs/img/verify.png` 那种「工具输出了一张说不的表」的画面，比任何排版都有效；第二张用 `docs/img/page.png`（页面上被划出来的那句原话）。六张以内，别做九宫格。
- **别写「AI 全自动开发的」。** 这个词在这个平台上会让人以为是又一个套壳应用；如果被问到就直说，但不要当作封面文案。
- **受众是研究生不是工程师。** 正文里一个命令行都不用出现，出现「pip install」这篇就死了。
- **准备好被问「用什么软件写的论文」。** Overleaf 用户最能直接受益，`.tex` 现在直接能读。
