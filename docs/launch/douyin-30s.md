# 抖音 30 秒

*先说清楚一件事：这条视频的受众不是这个工具的用户。看抖音的论文写作者不会为了一个 CLI 去装 Python。所以这条素材的作用是**让「让程序去核对论文里的数字」这件事被更多人知道**，而不是拉安装量。真要投，投的是「这个东西存在」这个信息，转化到主页或者评论区。*

*也正因为如此，不要在这里说任何一句技术细节，也不要提 AI。*

---

**标题（三选）**

```
论文里的每个数字，我都让程序去PDF里对了一遍
```

```
导师：这个数据你确定吗？我：等我三秒
```

```
我给自己写了个机器人，专门挑自己论文的错
```

---

**30 秒脚本**

| 秒 | 画面 | 台词 |
|---|---|---|
| 0–3 | 论文正文特写，光标停在一句「the corpus contains 154,391 utterances」上 | 「这句话你确定吗？」 |
| 3–8 | 切到手机模拟器或录屏：一个黑底终端，敲一行命令 | 「我把论文里每个数字，都写清楚了它在哪份 PDF 的第几页。」 |
| 8–16 | 终端输出：四条绿色的 `quote found on page 6` / `page 7` / `page 14` | 「然后就让它自己去对。」 |
| 16–22 | 输出里跳出一条红色的 `quote missing`。画面停住，红色圈出来 | 「这一条，它说找不到。」 |
| 22–27 | 切回论文正文，那条引用的句子被划掉 | 「因为这句话，我引错论文了。」 |
| 27–30 | 黑屏一行白字 | 「已经写了一个月，它每次都还在挑我的错。」 |

**封面（第一帧）**

不要放终端截图——抖音的封面缩小到 1/6 屏宽，终端字全糊。用论文正文特写 + 一句大字幕：「这句你确定吗？」

---

## 制作备注

- **画面里不要出现英文命令行。** 出现代码就掉一档完播率。终端的画面只保留输出结果，输入那一行甚至可以剪掉。
- **那段红色输出必须是真实录屏。** 仓库里 `demo/` 跑一下就有：`cd demo && citevouch verify manuscript.md`。录屏分辨率至少 1080 宽，字号调大两档。
- **不出现链接、不出现「链接在主页」之外的引导。** 抖音站内引流规则严，一句「主页有」就够。
- **不要做九宫格轮播。** 这条素材是单条视频，节奏比信息量重要。
- **如果只有一次机会，投 V2EX 和 Show HN，不要投抖音。** 前两个平台的人会真的去 clone；抖音的人会点赞然后划走。这条文案存在的意义是「如果哪天要做，不至于从零想」。
